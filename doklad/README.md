# Доклад-презентация: 4ПР и «Великая перезагрузка»

Сайт-презентация к теме 16 курса — «О Четвёртой промышленной революции и Великой перезагрузке
(доклад для обсуждения и дискуссии)», с разбором в оптике полицентризма (Перская, Эскиндаров).

| файл | что внутри |
|---|---|
| `index.html` | сам сайт: 14 разделов, графики по данным ВТО и МВФ, схема «единый центр / полицентризм», вопросы к дискуссии, список литературы. Один файл, без сборки и зависимостей |
| `text-doklada.md` | текст выступления к слайдам, 12–14 минут |

## Как открыть

Открыть `index.html` двойным щелчком в любом браузере — этого достаточно. Для показа с
проектора удобнее полноэкранный режим (F11).

- Стрелки **←** и **→** — переход между разделами, обычная прокрутка тоже работает.
- Кнопка **тема** — светлое или тёмное оформление (выбор запоминается в браузере).
- Кнопка **печать / PDF** — печать в PDF с отдельными стилями: навигация и кнопки скрываются,
  разделы не разрываются между страницами. Это же способ сдать доклад файлом.

Шрифты (Golos Text, Unbounded, IBM Plex Mono) подгружаются с Google Fonts: без интернета
вёрстка сохранится, но начертания подменятся системными.

## Что поправить под себя

- Строка **«Докладчик»** на обложке — в блоке `cover__meta`, там сейчас «Ф. И. О., группа».
- Название дисциплины — там же, первой строкой.
- Цифры в разделе 07 и подписи к графикам помечены источниками; при обновлении данных менять
  нужно и значение в тексте, и координаты столбца в SVG (высота считается от базовой линии).

## Источники данных

World Trade Statistical Review 2023 (WTO); World Economic Outlook, April 2022 (IMF); Global
Trade Update, June 2023 (UNCTAD); материалы WEF 2016–2021. Полный список — в разделе 14 сайта.

## Публикация через GitHub Pages

Ветка подготовлена к раздаче через Pages: в корне лежат `index.html` (переадресация на
`doklad/`) и пустой `.nojekyll`, чтобы GitHub отдавал файлы как есть, без обработки Jekyll.

Включение — в настройках репозитория: **Settings → Pages → Source: Deploy from a branch**,
ветка `claude/presentation-website-design-bxyh98`, папка `/ (root)`, **Save**. Через минуту-две
сайт поднимется по адресу `https://gordeevev000-pixel.github.io/-/`, доклад — там же или по
`/doklad/`. Репозиторий публичный, так что ссылка откроется у любого без входа в аккаунт.

Корневой `index.html` нужен только для Pages: он ничего не делает, кроме переадресации.
