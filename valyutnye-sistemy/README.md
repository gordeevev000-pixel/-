# Парижская, Генуэзская, Бреттон-Вудская и Ямайская валютные системы

Тема 2 «Валютные отношения в мировой экономике», вопрос 5.

| файл | что это |
|---|---|
| `doklad.docx` | доклад, 20 страниц: титульный лист, содержание, 6 разделов, заключение, 16 источников. Times New Roman 14, интервал 1,5, поля 30/15/20/20 мм |
| `doklad.pdf` | тот же доклад в PDF |
| `site/index.html` | презентация-сайт из 20 слайдов: откройте файл в браузере |
| `prezentaciya.pdf` | та же презентация в PDF: 20 страниц 16:9, по одной на слайд |
| `tekst-vystupleniya.docx` | текст выступления по слайдам, ≈ 9 минут |
| `src/` | скрипты, которые собирают доклад, рисунки, текст выступления и PDF презентации |

## Как пользоваться презентацией

- Кнопка **«Показать слайды»** (или клавиша `P`) открывает показ на весь экран.
- `←` `→`, пробел или клик по слайду листают слайды, `F` включает и выключает полный экран, `Esc` закрывает показ.
- Что говорить на каждом слайде — в файле `tekst-vystupleniya.docx`.
- Графики интерактивные: наведите курсор на столбик или точку. Ползунок на слайде 6 меняет стоимость пересылки золота и двигает «золотые точки».

Перед сдачей заполните в `doklad.docx` поля в квадратных скобках на титульном листе: вуз, кафедру, дисциплину, ФИО и группу.

## Пересборка доклада

Нужны Python 3 с `matplotlib` и `pymupdf`, Node.js с пакетом `docx` и LibreOffice Writer.

```bash
./src/build.sh
```

Скрипт рисует иллюстрации, собирает `.docx`, проставляет номера страниц в содержании и сохраняет PDF.
